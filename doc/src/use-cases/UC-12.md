## UC-12

* **ID / Code:** UC-12
* **Use Case Name:** Consult financial dashboard and reports
* **Description:** Inspect explainable financial indicators, export authorised reports and prepare accounting packages.
* **Primary Actor:** Administrator
* **Other Initiating Contexts:** Previously authorised weekly or monthly summary schedules execute as internal system behaviour for currently authorised recipients.
* **Supporting Actors:** Communication Service (scheduled internal summaries)
* **Scope:** Turbine internal invoicing and collections application.
* **Level:** User Goal
* **Related requirements:** BR-05, BR-06; UR: UR-09, UR-11; FR: FR8, FR8.1, FR8.3, FR8.4, FR8.5, FR8.6, FR8.7, FR8.8; NFR-02, NFR-03, NFR-04, NFR-05.
* **Source:** E pp. 7, 11, 14-15.
* **Stakeholders & Interests:**
  * *Administrator:* trace totals to invoices and allocations.
  * *Turbine management:* review financial performance.
  * *Accounting firm:* receive versioned accounting packages without an application account.
* **Preconditions:** Interactive access requires authentication, Administrator authority and explicit financial-report permission. Scheduled execution requires a previously authorised schedule and current permission for its report scope and recipients.
* **Postconditions:** Indicators/exports retain filters and generation time; accounting packages retain period/version. Downloads enforce scope and currency distinctions.
* **Success Guarantee:** Selected totals can be drilled down and exported reproducibly for the permitted period and scope.
* **Minimal Guarantee:** An incomplete report is not labelled complete and unrelated currencies are not silently summed.
* **Trigger:** The Administrator selects a dashboard, report or accounting package, or a configured weekly or monthly summary becomes due.
* **Main Success Scenario:**
1. The Administrator selects the weekly, monthly, quarterly or annual period and customer, manager, country, sector, status, type or currency filters.
2. The system calculates invoiced, collected, outstanding, overdue, collection-time, recurring-revenue and next-month forecast indicators.
3. The Administrator selects a figure to inspect.
4. The system displays the contributing records within current scope.
5. The Administrator requests a CSV export, readable PDF report or monthly or quarterly accounting package.
6. The system generates the selected report or package of invoices, corrections, collections and preserved PDFs.
7. The system records filters, actor, generation time, period and package version.
8. The system provides the output after a current download permission check.

* **Extensions:**
  * **1a.** Financial-report permission missing:
    1. The system denies access, including for a technical Super Administrator account without this capability.
  * **2a.** Several currencies present:
    1. The system separates totals unless an approved conversion policy applies.
  * **2b.** Budget targets requested:
    1. The system retains the current Out of Scope restriction despite broader BR-05 and UR-11 wording.
  * **6a.** Report exceeds the configured background threshold:
    1. The system starts background generation under FR8.7.
    2. The system shows actual job status.
    3. The system notifies the user when the output is ready.
  * **6b.** Report generation fails:
    1. The system records the failed stage without presenting a partial output as complete.
  * **8a.** Export retention expires:
    1. The system applies the configured retention period to generated exports.
  * **1b.** Summary schedule configuration:
    1. The Administrator sets weekly or monthly generation for authorised recipients only.
    2. The system records the authorised schedule.
  * **1c.** Summary occurrence due:
    1. The system rechecks schedule authority and recipient permissions.
    2. The system generates the scoped summary.
    3. The system requests delivery through Communication Service.
    4. The system records the observed sending result.
  * **1d.** Scheduled recipient no longer authorised:
    1. The system withholds the summary from that recipient.
